T2DM Study Data Entry - standalone app (works offline)

HOSTING (free, one time) - GitHub Pages
1. Create a free account at github.com and make a new PUBLIC repository (e.g. t2dm-data).
2. Add file > Upload files > upload ALL files from this folder (index.html, manifest.json, sw.js, xlsx.mini.min.js and the 3 icon-*.png). Commit.
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder / (root) > Save.
4. After about a minute your app is at https://YOURUSERNAME.github.io/t2dm-data/
   (the files only contain the app, never patient data, so public is fine)

INSTALL ON PHONE
- iPhone: open the link in Safari > Share > Add to Home Screen.
- Android: open the link in Chrome > menu > Install app / Add to Home screen.
Open it once online; after that it works offline.

NOTES
- Records are stored on that phone only. Export to Excel regularly as a backup.
- Use the Home Screen icon only for entering data.
